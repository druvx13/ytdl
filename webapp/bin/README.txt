The yt-dlp Linux binary is bundled in this directory (yt-dlp v2026.02.21).
It is picked up automatically — no configuration needed.

To update to a newer version:
  Download the latest binary from https://github.com/yt-dlp/yt-dlp/releases/latest
  and replace this file (webapp/bin/yt-dlp), then chmod +x yt-dlp (Linux/macOS).

For Windows servers, place yt-dlp.exe here instead.

This directory is blocked from direct web access via .htaccess.
